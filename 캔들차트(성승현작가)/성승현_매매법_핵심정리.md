## 1. 핵심 기준선 — 월봉 MA10

> *"주가는 이 월봉 10이평을 절대 깨지 않고 그 위에서 논다."*  
> — 성승현 유튜브 영상 자막 직접 확인

| 용어 | 실제 의미 |
|------|---------|
| 월봉 10이평 | 10개월 이동평균선 (월봉 차트 기준) |
| 일봉 환산 | 일봉 200일 이동평균선과 동일 |
| 주봉 환산 | 주봉 24이평선과 동일 |

> ⚠️ 독스 요약 파일 일부에 "월봉 12평"으로 기록된 것은 **잘못 들은 것**. 영상 자막 확인으로 **MA10 확정**.

## 2. 매매 3원칙

```
매수: 월봉 종가 > MA10 (상향 돌파 시)
보유: MA10 위에 있는 한 → 중간 하락에도 무조건 홀딩
매도: 월봉 종가 < MA10 (하향 이탈 시) → 예외 없음
```

- **종가 기준**: 장중 이탈은 무시, 월봉 말일 종가로만 판단
- **확인 주기**: 매달 말일 단 1회 (월 3~4시간으로 충분)

## 3. 차트 5대 분석 요소

사부님 명언:
> *"거래가 두 번 이루어지면 캔들이 하나, 캔들이 두 개면 파동이 하나, 파동이 두 개면 추세가 하나. 이 모든 것은 이평선 위에 존재한다."*

| 순서 | 요소 | 핵심 |
|------|------|------|
| 1 | **거래량** | 유일한 실체. 세력도 속일 수 없음 |
| 2 | **캔들** | 시가·종가·고가·저가 4개 데이터 시각화 |
| 3 | **패턴** | 캔들 조합이 만드는 상승/하락 신호 |
| 4 | **추세** | 패턴이 방향성을 띄면 추세 형성 |
| 5 | **이평선** | 지지선/저항선 역할. MA10이 핵심 |

> 보조지표(RSI·MACD·볼린저밴드 등) 불필요. "보조는 보조일 뿐."

## 4. 캔들 꼬리 분석

| 꼬리 유형 | 의미 |
|----------|------|
| 짧은 위꼬리 | 자연스러운 이식 매물 소화 → 정상 |
| **긴 위꼬리** | 강력한 매도 물량 출현 → **악재 신호** |
| 긴 아래꼬리 | 매도 물량을 매수세가 받아냄 → 긍정적 |

---

## 5. 주요 패턴

### 상승 패턴
| 패턴 | 설명 | 신호 |
|------|------|------|
| 쌍바닥 (W형) | 저점 두 번 터치 후 반등 | 매수 |
| 3중바닥 | 쌍바닥보다 강력 | 강력 매수 |
| 컵위드핸들 | 원형 바닥 + 눌림(핸들) | 핸들에서 매수 |
| 돌반지 | **돌**파+**반**등+**지**지 | 일봉 10일선 돌파 시 매수 |

### 하락 패턴
| 패턴 | 설명 | 신호 |
|------|------|------|
| 쌍봉 | 고점 두 번 형성 후 하락 | 매도 준비 |
| **헤드앤숄더** | 왼어깨·머리·오른어깨 | **최강 하락 신호** |
| **저승사자 캔들** | MA10 이탈 후 장대 음봉 | **즉시 매도** |

> 저승사자 캔들은 여러 개 음봉을 **합치기(뽀개기)** 해서 판단. 세 개 음봉을 합치면 장대 음봉 하나.

## 6. 탑다운 분석 (매월 확인 순서)

```
① 미국 3대 지수 (나스닥 → S&P500 → 다우)
② 유럽 (독일·프랑스·영국)
③ 제조업 국가 (중국·일본·대만)
④ 한국 (코스피·코스닥)
⑤ 개별 종목
```

- 글로벌 상승비율 70% 이상 → 적극 매수
- 50~70% → 선별적 접근
- 50% 미만 → 신규 매수 자제

---

## 7. 돌반지 패턴 (핵심 매수 타점)

```
① 바닥권에서 평소 대비 3배 이상 거래량 + 장대 양봉 (1차 저점)
② MA10까지 조정 후 쌍바닥 형성 (2차 저점 > 1차 저점)
③ 일봉 10일선 돌파 장대 양봉 종가 → 매수
   (더 정확히: 다음날 3분봉 첫 캔들 거래량 전일 대비 200% 이상 시 매수)
```

## 8. 눌림목 매매

이미 많이 오른 종목 대응법:
- 월봉/주봉 MA10 근처에 **지정가 미리 걸어놓기**
- 눌림목에서 음봉에 매수 → 손익비 우수
> *"고수는 음봉에서 사고, 하수는 양봉에서 따라 들어간다."*

## 9. 거래량 분석

| 상황 | 의미 |
|------|------|
| 바닥권 거래량 3배+ | 상승 추세 반전 신호 |
| 눌림목 거래량 감소 | 세력 이탈 없음 → 긍정적 |
| 돌파 구간 거래량 증가 | 매물 소화 완료 → 긍정적 |
| 고점 거래량 증가 | 세력 물량 털기 가능성 |
| 고점 거래량 감소 | 상승 지속력 약화 |

## 10. 핵심 원칙 요약

1. **차트는 예측이 아닌 대응 수단**
2. **매매는 안 할수록 좋다** (월 1회, 말일 종가만 확인)
3. **추세가 살아있으면 어떤 상황에도 버텨라**
4. **MA10 이탈 시 예외 없이 즉시 매도**
5. **전업 투자 금지** — 직장 + 투자 투 트랙 유지
6. **보조지표 불필요** — 5대 요소만으로 충분
7. **큰 회사일수록 차트가 잘 맞는다**
8. **프론티어 되지 말고 팔로워 되라** (수급 확인 후 진입)
